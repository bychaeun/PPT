# 효산 LPL — 다음 문을 여는 지식

별도의 발표용 인터랙티브 랜딩페이지입니다. 기존 효산 백과사전의 코드를 수정하지 않습니다.

## 미리보기

`node preview.mjs` 실행 후 http://127.0.0.1:4186 을 엽니다.
정적 사이트이므로 `dist/index.html` 파일을 직접 열어도 사용할 수 있습니다.

## 구성

- 스크롤 인트로: 효산 LPL 제목 → 문 → 영업사원 픽토그램 → 흰 화면
- 제작 목적: 거래처를 오가는 영업사원과 모바일 자료실
- 휴대폰으로 모이는 자료
- 7개 카테고리: 마우스 오버, 키보드 초점/방향키, 모바일 터치 전환
- 개발일지: 모으다 → 연결하다 → 다듬다
- Google Sheets 관리 화면 4종: 클릭으로 1초 자동 넘김 재생/정지, 탭으로 직접 선택
- 도착한 문부터 순서대로 열리는 도입부와 스크롤로 문 안에 들어가는 마지막 장면
- 실제 효산 백과사전 연결

## 자료와 표현 범위

실제 메뉴와 기능 설명은 사용자가 제공한 효산 LPM Pattern Library V1 개발일지 및 https://bychaeun.github.io/hyosan/ 의 공개 프런트엔드에 근거합니다.
사용자 요청에 따라 로그인된 실제 앱 화면을 캡처해 `dist/captures/`에 저장했습니다. 목록/상세 캡처가 전환되는 발표용 미리보기이며, 로그인 토큰이나 세션은 저장하지 않았습니다.
휴대폰 및 카테고리는 실제 앱 캡처입니다. 떠 있는 자료 카드의 텍스처는 장식용 예시입니다. 캡처는 촬영 시점의 데이터이며 자동 갱신되지 않습니다.
Google Sheets 화면은 사용자가 제공한 HYOSAN_LPM_LIVE_DATA의 PATTERN_DESIGN, HYOSAN_LPM, SPECIAL_SPECS, EMBOSS_PLATE 탭을 캡처했습니다. 클릭 재생은 로컬 이미지 4장을 전환하며 원본 시트는 수정하지 않습니다.
개발일지의 기한과 진행률은 현재 상태로 간주하지 않고, 게시하지 않았습니다.

`dist` 안의 모든 파일과 captures 폴더를 정적 호스팅에 올리면 동작합니다. Google Fonts를 제외하면 외부 라이브러리 의존성이 없습니다. 폰트가 로딩되지 않을 때는 시스템 한글 글꼴을 사용합니다.
GitHub Pages에 추가한다면 기존 백과사전을 덮어쓰지 않도록 별도 경로(예: `presentation/`)에 이 세 파일을 배치할 수 있습니다. 현재 저장소에 게시하거나 Pages 설정을 변경하지 않았습니다.
